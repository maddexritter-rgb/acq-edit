# ACQ Edit contributor contract
This is a new toolkit, not the live production skill tree. Never write into a user's global skills, vault, installed editor, or unrelated projects during development.
Read docs/STATUS.md before claiming support. A passing unit test does not prove native render quality.
A project has exactly one immutable backend. No converter or alternate editor may satisfy a native operation.
Read native state before revisions. Preserve manual changes; uncertain native outcomes require reconciliation, not blind replay.
Use packaged skill owners. Assembly Design owns editorial choice; adapters execute exact plans, never invent cuts.
Sources and published versions are immutable. Feedback always targets its original version. New versions require new review.
No credentials, personal profiles, licensed media, real project evidence, or brain content in Git. Preserve third-party notices.

When the user asks to install, get started, connect services or resume setup, read the agent onboarding contract in docs/ONBOARDING.md first. Act as their friendly setup guide, give one next step at a time and resume existing progress. Before first production use on a new machine, follow that guide and resume missing setup steps. Development and read-only questions do not require onboarding. Frame/Monday delivery belongs to the packaged monday owner; setup never authorizes an upload.

For direct stage requests (captions, Assembly Design, reframing, music or delivery), read docs/SKILLS.md. Run only the requested owner and necessary prerequisites; do not force full editing onboarding for standalone delivery.

Premiere connector lock: use only this installation’s ACQ Edit Agent MCP through the toolkit native adapter or verified repository helper. Never use ambient/global Premiere tools (including mcp__premiere_pro), old MCP Bridge/production panels, or a global default profile. Installed does not mean authorized. If the verified ACQ Edit Agent route is unavailable, stop and repair its setup; never switch bridges. Preserve unrelated installed integrations.

For new editing jobs ask FilmCraft or Premiere unless specified. Premiere ends at a verified saved editable timeline left open; no automatic export, room or upload. FilmCraft ends with a verified export and the room with current-chat revision handoffs. Follow docs/NATIVE_COMPLETION.md and docs/EDITOR_HANDOFF.md. Runtime helpers use toolkit Python; preserve exact host guards and report unqualified versions.

Execution policy: use the existing chat to perform editing. `build` prepares a current-chat job; use session-start and session-complete with verified evidence. Never start a second Claude/Codex session, require CLI login, run an agent smoke test, or demand saved command approvals for ordinary onboarding/editing. Separate agent workers are not a supported product mode. Run internal toolkit commands yourself; never send users to a terminal, ask them to learn commands, or guide a second agent login. See docs/AGENT_WORKFLOW.md.

A pasted Google Drive file or folder link routes to the packaged footage-fetch owner. Homebrew/Workbrew includes rclone. Use drive-status and guided drive-login or drive-connect when needed; the user should not have to identify file IDs, downloader commands, or connection syntax.
