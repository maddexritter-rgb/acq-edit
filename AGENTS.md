# ACQ Edit contributor contract
This is a new toolkit, not the live production skill tree. Never write into a user's global skills, vault, installed editor, or unrelated projects during development.
Read docs/STATUS.md before claiming support. A passing unit test does not prove native render quality.
A project has exactly one immutable backend. No converter or alternate editor may satisfy a native operation.
Read native state before revisions. Preserve manual changes; uncertain native outcomes require reconciliation, not blind replay.
Use packaged skill owners. Assembly Design owns editorial choice; adapters execute exact plans, never invent cuts.
Sources and published versions are immutable. Feedback always targets its original version. New versions require new review.
No credentials, personal profiles, licensed media, real project evidence, or brain content in Git. Preserve third-party notices.
