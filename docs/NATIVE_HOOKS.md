# Opening headlines removed

Opening text headlines and the `text-hook` skill are no longer included in ACQ Edit. New installations do not expose an owner or native creation/revision route. Spoken editorial hooks, body captions, and requested motion graphics are separate capabilities and remain available.

Existing published media, feedback, native project files, and pinned installations are not rewritten. Use the original pinned toolkit for a legacy project with a `hookContract`; the current native execution route refuses that contract explicitly before editor access. Do not delete its contract to bypass verification or load a global skill to recreate the removed capability.
