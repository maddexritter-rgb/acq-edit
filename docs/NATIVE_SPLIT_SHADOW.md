# Native split-screen seam shadow

The framing owner supports an explicit FilmCraft revision for existing equal-height,
stacked native camera panels. Use the repository's
`distribution/skills/horizontal-to-vertical/scripts/filmcraft_split_shadow.py`.
Supply the native project, a new work output directory, the pinned FilmCraft binary,
a JSON array of exact layout sequence IDs, and an explicit profile.
`assets/profiles/native-split-shadow.json` records the saved reference settings;
backend blur parity remains a rendered review decision.

The helper preserves both existing panel tracks. It adds a full-canvas shadow-only
nest linked to the same upper camera sequence, then a clean linked upper-panel
occurrence. It changes no original camera keys, dialogue, captions, text, timing,
or source selections. Custom layouts/effects and previously modified shadow layouts
are refused. Save/reopen verifies every pre-existing project field, owned shadow
parameters, panel identities and clocks. The parent is never overwritten.

Use `--export-receipt RECEIPT --binary BINARY --media NEW_MP4 --session NEW_SESSION`
for this revision's guarded native export. It verifies the exact append-only revision
and owned shadow before encoding, records a construction check and native job,
waits for completion, then rechecks unchanged native state. Inspect first/middle/last
frames of each split interval and layout transitions; decode the complete output and
compare decoded audio with the parent before copying into a new delivery version.
The procedure does not certify listening or Premiere pixel parity.

This is a framing-only checkpoint route, including preservation of legacy native
finishing layers. Do not treat its receipt as a generic review-room publication
receipt or bypass an adapter's unknown-effect checks. Other native panel revisions
must reconcile the added linked tracks first. Premiere's installed project is never
opened by this helper; its own native preset route remains separate.
