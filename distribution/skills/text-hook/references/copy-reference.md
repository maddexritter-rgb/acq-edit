# Copy reference: one central idea

Source: [The Copy Rule I Learned From The Best Copywriter I Know](https://www.youtube.com/watch?v=OyGKFhTf0go). Read from its English automatic-caption transcript on 2026-10-21; automatic captions can contain transcription errors. This is a practitioner explanation, not proof of a universal performance law.

- **01:09–02:03:** Packing unrelated benefits together weakens the message. Choose a single idea the audience can readily understand and believe, with a detail that makes it interesting.
- **02:05–03:00:** Supporting material should reinforce the central idea. Applied to clips, the actual dialogue must deliver the headline's promise.
- **03:20–04:37:** Choosing the central idea is the demanding part. Select it deliberately before polishing the sentence.

Application to text hooks: generate competing ideas, select one, then write and clean the headline. Do not compress every useful point in the clip into one overlay. These are adaptations for short-form headlines; the video discusses sales copy more broadly.

Do not import the video's sales statistics as verified facts, require contrarian wording, or infer that every hook needs a sales pitch. Source fidelity and the user's slop-detector preferences still apply.
