# Test an assembly change against footage

Use this mode when improving the editing method or explicitly testing an upgrade;
it adds no approval gate to normal clip construction.

Freeze the source identities, complete interactions, live playbook versions and
retrieval exclusions before designing. Hold out the evaluation recording and its
prior selections, finals, feedback and near-duplicate excerpts from retrieval.
Apply the clean-room rule in the main skill. A case already used to tune the method
is a development replay, not a held-out test.

Build the new paper cut from the full source. Only after it is frozen, compare it
with the baseline on the same source. Review the actual joined dialogue and played
seams, not the prose explaining why the edit is good. Keep the selection, compiler
receipt, frame map, project/sequence identity and rendered review asset together.

Record concrete findings with source word ranges or source/timeline time:

- Does the opening establish a clear promise without a competing introduction?
- Which repeated meaning, empty setup, filler or dead space was actually removed?
- Which mechanism, condition, example, reaction or causal bridge had to survive?
- Does the ending resolve the opening, including later source qualifications?
- Did any join clip speech, import an excluded word, leave empty delay or change
  what a speaker appears to answer? State unresolved seams individually.

Runtime, word count and cut count describe the edit; none establishes improvement.
Report failures as well as gains. A shorter but misleading clip loses. A synthetic
word-map test verifies a compiler behavior, not editorial judgment or audio quality.

For human comparison, use neutral A/B labels and preserve the editor's actual
keep/change/delete judgment, reason and exact revisions. Do not infer approval from
tool success. Route new evidence and exceptions to `editorial-brain-ingest`; unmatched
meeting notes stay research. A verified native-final selection precedent establishes
only the named spoken choices against an inspected finished native sequence; it does
not certify delivery or acoustic seams. Generalize repeatable decisions after checking contrary
cases; do not turn one successful example into a mandatory structure.
