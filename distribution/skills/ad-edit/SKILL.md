# Ad edit — paid creative house style

For any Premiere access, follow [Premiere Agent startup and advanced stage routing](../edit/references/premiere_start_here.md). Use the configured new bridge by default; if MCP tools are missing in this chat, use its CLI. Keep this skill’s existing creative scope and read-only limits.


Paid ads are **not** organic clips. Different caption system, different structure, different
safe zones, different close. This skill owns paid creative end to end.

> **Read [`references/ad_style_spec.md`](references/ad_style_spec.md) before cutting anything.**
> Every value in it was measured off shipped ads, not guessed.
>
> **Read [`references/export_sop.md`](references/export_sop.md) before exporting anything.**
> Creative goes straight from editor to media buyers with **no approval step** — the editor is
> the gate. That file carries the mandatory disclaimer, the banned-content list, naming, and
> the handoff template.

an approved editorial clip plus a paid CTA. Do not restyle an approved cut merely because
the destination is paid; the workshop reference owns that route.

## The format that scales

A callout ad is **one master VO with the industry name swapped at the front**. Everything after
the callout is identical. That is what makes N industries cheap.

Two proven base scripts (see the spec for full text):
- **Gift** — *"[Industry] business owners. The best gift I could possibly give you…"* (~49s)
- **Mortality** — *"Most [industry]s don't change. They live the same six months…"* (~32s)

Before producing a batch, get the priority industry list from the person who owns ad
performance. Do **not** build for every landing page — build for the highest-ROAS verticals.
Check `__ACQ_ASSETS__/brand-assets/ad-performance/` for the latest by-industry ROAS pull
before asking — it may already answer which verticals to build.

## Workflow

### 0. Raw footage that isn't ad-ready yet → `/edit` does the mechanics, this skill does the ad layer
If the source is still raw (horizontal, uncut, has bad takes/ums/pauses in it) rather than an
already-trimmed talking-head master, **run `/edit` first** to get it to the state step 1 below
assumes. This is the repeatable two-skill pipeline for "turn raw/organic footage into an ad":

1. **`/edit`** — mines/cuts bad takes and filler, reframes 16:9→9:16 with face tracking, produces
   a clean vertical master + its word-level transcript. It owns ALL the organic mechanics (cut,
   reframe, base captions) exactly per the lane table above — this skill never re-implements them.
   For a heavy production batch this means the full RUNBOOK.md spine (Premiere timeline, human
   review gate, 6 parallel audits). For a quick/test pass, the lightweight equivalent is: transcribe
   → eyeball the word-level transcript for filler/false-starts/dead-air >1.2s → cut with an engine
   (`_shared/precision_cut.py` or a single `-to` trim if the take is already clean) → reframe with
   `horizontal-to-vertical`'s `qa_reframe_v2.py --preset alex-listicle` (or whichever preset fits).
2. **`/ad-edit`** (this skill) — takes that clean vertical master + transcript and adds everything
   ad-specific: hook headline, ALL-CAPS pill captions (this skill's own caption track, generated by
   `render_ad.py` — it does not reuse whatever caption style step 1 applied), CTA close, disclaimer,
   and VFX/graphics from the asset library below.

**Splicing a separate CTA clip onto the tail** (rather than a graphic-only CTA over the organic
footage): reframe the CTA clip the same way, then concat with a short crossfade —
`xfade=transition=fadewhite:duration=0.2` (video) + `acrossfade=d=0.2` (audio), both inputs
normalized to the same fps/canvas first. This is the same splice convention `organic-bolt-on`
uses — **but don't confuse the two pipelines**: `organic-bolt-on` is for already-vetted,
already-vertical IG clips getting a pre-shot CTA spliced on with no ad-style graphics layer;
this workflow is for raw/still-horizontal footage that needs the full cut+reframe pass AND the
ad-style CTA/VFX finish on top.

### 1. Prep
- Source cut on disk (the talking-head master, already trimmed).
- Word-level transcript → `long-form-ingest`, or `mlx_whisper` with `word_timestamps=True`.
- Pick the crop centre on the subject's face (`crop_x`, `crop_w`) for the 9:16 reframe.

### 2. Mark the beats — anchor to PHRASES, not seconds

Any beat time (`cta_at`, `hook_end`, `overlays[].at`) accepts **a phrase from the VO**
instead of a number:

```json
"cta_at": "so go grab it",
"overlays": [{"type": "seq", "at": "we made this free tool", ...}]
```

This matters because masters get re-cut. Trim one "um" out and every hardcoded timestamp
drifts; phrase anchors just re-resolve against the new transcript. The renderer prints the
resolved times so you can sanity-check spacing, and hard-fails on a phrase it can't find
rather than silently misplacing a graphic.

Put `cta_at` on the line where the offer is actually named.

### 3. Render
```bash
python3 scripts/render_ad.py config.json
```

```json
{
  "source": "/path/master.mp4",
  "transcript": "/path/transcript.json",
  "out": "AD_9x16.mp4",
  "hook_end": 5.4,
  "card": "assets/product_card_example.png",
  "card_in": 15.0, "card_out": 21.0,
  "cta_at": 24.2,
  "cta_line1": "Get the free scaling roadmap",
  "cta_line2": "Click the link below",
  "crop_x": 1912, "crop_w": 1215
}
```

Everything else — palette, pill geometry, safe zones, text normalisation — is baked in from
the spec. `card` is optional; omit it for a straight talking-head ad.

### 3b. Graphics + B-roll

Overlays are a timed list in the config. Five types:

| type | what | source |
|---|---|---|
| `png` | static card | `make_graphics.py` (stat cards, chip rows) |
| `seq` | **animated graphic, alpha** | Remotion → PNG sequence |
| `broll` | small video insert in a purple-glow card, speaker stays visible | any clip; 16:9 reads best |
| `cutaway` | **full-bleed labeled cutaway** (Hunter's real style, added 2026-08-21) — blurred/darkened live backdrop + big rounded video card + a purple badge naming the segment (`"badge": ["SALES","WORKSHOP"]`) | any clip; see `ad_style_spec.md` §4 |
| — | CTA pill | **Remotion `CTAPill`** (gradient + glass + shine). Set `"cta_builtin": false` and add it as a `seq` overlay with `"hold": true`. The PIL fallback (`cta_builtin: true`, the default) already matches the real ad closely and auto-shrinks its text to fit — use it unless a specific animated variant is wanted. |

**Animated graphics (Remotion).** `remotion/` holds the compositions.
```bash
cd remotion && npx remotion render src/index.tsx ReportCard out/frames \
  --sequence --image-format=png
```
Render a **PNG sequence**, not ProRes — `--prores-profile=4444` came back without an
alpha channel, and the sequence drops straight into a `seq` overlay anyway.
`node_modules` is symlinked from the `promo` skill's glass template, so there is nothing
to install.

### 3c. Heavy-broll single-clip recipe (repeatable, added 2026-08-21)

For a talking-head clip that needs to read as a produced ad rather than a static self-tape
(e.g. bolting a CTA take onto itself with nothing else happening on camera the whole time):

1. **Reframe wider than the preset default if the subject fills too much of the frame.**
   `alex-listicle` defaults to `--zoom 1.6`; 1.1–1.3 reads less claustrophobic for a close
   that's meant to feel like an ad, not a selfie. Check the result before locking it in —
   there's no universal right number, only "does it look cramped."
2. **Move the chip caption to sit on visible skin** (the neck/chest band between
   beard/chin and shirt collar), not down on the chest logo. Measure it per clip — every
   subject's framing differs — the same way `ad_style_spec.md` §3 measures the reference:
   sample pixel colors down a vertical line to find where the beard ends and skin starts,
   then set `chip_cy` to the center of that band. If the CTA pill's `cta_y` and the
   cutaway card's `card_y` were tuned for the OLD chip position, moving the chip requires
   re-checking both for overlap — they don't auto-adjust.
3. **Schedule `cutaway` overlays with ZERO gaps for continuous broll coverage.** Pick
   anchor phrases across the transcript, then set each cutaway's `dur` to end EXACTLY
   where the next one's `at` begins — `dur = next_at - this_at`, not an independently
   guessed length. **This is the #1 way this recipe breaks**: an underestimated `dur`
   leaves a real scheduling gap (not a fade-blend issue) and the talking head flashes
   through for a few frames. `draw_cutaway` already hard-cuts (no fade dip) between any
   two cutaways scheduled under 0.6s apart — that only helps once the schedule itself has
   no gap. **Verify with exact frame-index extraction** (`ffmpeg -i out.mp4 -vf
   "select='between(n\,190,205)'" -vsync 0 f%03d.png`), never a fractional `-ss` timestamp
   on a retimed/re-encoded stream — imprecise seeking there can *look* like a ghosting
   defect that isn't actually in the file (chased this exact false lead for a while before
   confirming the real output was clean frame-by-frame).
4. **`music` + `sfx` config keys** mix a bed and one-shot transition sounds into the final
   audio. `music_db` around **-30** sits under the voice without fighting it (-22 read as
   "way too loud" in review). A quick click/whoosh `sfx` entry at each cutaway's `at`
   sells the cut — default its `db` to **-16** (a client caught -8 as "distracting," not
   the sound itself, just the level). Sources: `~/ai ads/_ASSETS/music-library/`,
   `__ACQ_ASSETS__/assets/sfx/`.
5. **`"speed": 1.1`** uniformly retimes the FINISHED render (not the source) — keeps every
   caption/cutaway/CTA locked to the now-faster voice instead of drifting out of sync.
   1.1–1.15x tightens pacing without sounding chipmunked; ask before going higher.
6. **Close on the small pill CTA** (`cta_builtin: true`, the default) rather than the
   full-screen end-card (`cta_fullscreen: true`, available but read as a worse ad in
   review — the small pill over the still-visible speaker is the one to default to).
7. **Badge (`cutaway` label) styling is locked** — see `ad_style_spec.md` §4 for the
   measured muted-glass palette. Known gotcha already fixed in `badge_img()`: the icon's
   radius + a real gap must clear where the text starts, or the icon and text overlap.

A full worked example (this exact recipe applied end-to-end) is saved at
`references/example_config_heavy_broll.json` — copy it as a starting point rather than
building the overlay list from scratch.

## Non-negotiables

1. **Default mode (`caption_mode: "chip"`, 2026-08-21) has NO separate big headline at
   all.** A small black CHIP caption runs identically from frame 1 — don't reintroduce a
   hook headline by habit. (The legacy `"headline"`/`"hybrid"` modes DO use a big headline
   as a hook-only device, first ~5s, never returning — that rule still applies to THEM.)
2. **The caption is the primary track and runs the WHOLE ad, including underneath the
   CTA pill — it never stops for the close.** Measured directly off a real shipped ad
   (f.io/G4BFDgKa): the caption chip is still visible under "CLICK BELOW / BOOK A CALL".
   (Legacy `"hybrid"` mode is the one exception — its purple pill caption does stop at the
   CTA; that's correct for that specific system, not for the default.)
3. **Never cross x=860.** The right action-button column eats it. This includes CTA copy —
   `cta_pill()` shrinks the font to fit; never let a long offer line clip past the edge.
4. **Never put the CTA pill below y=1500.** The platform's own description sits there.
5. **The disclaimer ships on every ad.** `"disclaimer": true` is the default; the renderer
   warns loudly if you turn it off. *"Information not typical. These are examples not
   guarantees. Results may vary."*
6. **Match the ad to its landing page.** If the page says "Designed for Plumbing Businesses
   over $1M", the ad should say the same words. Message match is the entire point of a callout.

## Known gaps (need a human or another pass)

- **Angle changes** — the reference cuts between camera angles from a multi-cam shoot. With a
  single-angle source, substitute punch-ins; they are weaker.
- **B-roll in the purple glow frame** — selection is editorial.
- **Headline behind the subject** — the reference mattes the person in front of the headline.
  Needs a video-matting pass; without it, keep headlines over dark background regions.
