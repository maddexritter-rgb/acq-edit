# Alex caption profile

The Alex profile is the existing approved Oliver/SPICE behavior. Preserve `oliver_format.py`, the
caption director, single-line pace-adaptive grouping, represented-voice color, Proxima Nova weight
ladder, cue-level size tiers, two-layer Premiere shadow, and drop-in animation. Existing direct calls
default to this profile. See `spice_caption_spec.md`, `oliver_caption_formatting_spec.md`, and
`yellow_quotes_rules.md` for the full rules.
