# Scoped shadow corrections

A retrieved `captions` policy may request a shadow correction for one production
family. It supersedes the general shadow recipe only in that exact scope and only
for the backend whose calibration has actually been inspected. Retain the current
appearance while that backend's comparison remains pending; note the requested
change in the normal handoff, with no new export gate.

Read the calibration file referenced by the external brand profile. Preserve the
official donor asset, font/size/weight, grouping, text, placement, timing, animation
and source edit. Build current/lighter variants on actual bright and dark footage
and both full-screen and split layouts at delivery resolution. Save numeric values,
backend/build, frame source clocks, rendered samples and the selected version.
Use actual native composed output to mark a backend verified. Distinguish an
agent's visual inspection from human approval. A raster preview is useful selection
evidence, not native renderer parity.

Filmcraft: `scripts/filmcraft_shadow.py:shadow_layer_props` accepts an optional
`shadow_profile` object. Pass it only from the matched caption-stage setting or
the exact pinned external calibration whose `backends.filmcraft.status` is
`native_inspected`. Preserve default calls for other productions. Keep all three
layers' text, placement and motion identical. Do not infer an active override from
the existence of candidate values; never pass Filmcraft blur units to another backend.

Premiere: calibrate on a job-owned donor copy through the existing exact-project
native caption route, save/reopen and inspect actual composed frames. Preserve the
official canonical preset. Bind the verified donor/effect state and calibration ID
to the current caption manifest; do not substitute guessed effect parameters or
claim the Filmcraft candidate proves Premiere appearance.
