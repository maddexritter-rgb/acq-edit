# Native caption donor assets

Generated Graphics dependency graphs extracted through the repository's guarded asset tool. No footage, audio, external paths or source project timelines are included. Fonts are supplied by the separately installed licensed bundle. Graph and donor-source hashes are in each profile.

- `alex`: Proxima Nova weight/italic donor runs and the existing caption appearance.
- `sharran`: Inter SemiBold 48-point upright and represented-speech synthetic-italic donors extracted from the reviewed V1 caption artifact. Use `donors_by_style` when preparing the build profile, retaining the supplied color, run and italic values. Default native position is 69%.

These are assets, not a substitute for authored semantic cards, live save/reopen, rendered inspection, or user approval of a new clip. Native outputs from this branch remain under review.
