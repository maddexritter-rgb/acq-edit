
## Requested split seam shadow

For a requested soft seam shadow on an existing equal-height native split, use
`scripts/filmcraft_split_shadow.py` with an explicit profile, exact layout IDs and
a new output directory. Preserve the linked upper-camera nest beneath a clean
copy, rather than darkening the entire composition or flattening the footage.
The repository's `docs/NATIVE_SPLIT_SHADOW.md` defines the guarded revision and
export route. Inspect split boundaries and both subjects in actual rendered frames.
Keep profile settings outside this reusable procedure.
